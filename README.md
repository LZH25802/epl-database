# Premier League Player Statistics Database

A modern, feature-rich Premier League Player Statistics Database web application built with HTML5, CSS3, Tailwind CSS, and JavaScript.

## Features
- **Team Rosters & Overview**: Browse all 20 Premier League teams with badge logos, stadium info, and squad lists.
- **Advanced Player Statistics**: Detailed stats including goals, assists, clean sheets, yellow/red cards, market values, and ratings.
- **Leaderboards & Top Performers**: Quick rankings for Top Scorers, Assist Providers, Best Rated Players, and Most Valuable Players.
- **Global Search & Filtering**: Instantly search players by name, team, position, or nationality.
- **Interactive Player Modals**: Click any player to view deep career stats and bio.

## Deployment
This is a fully static website. You can deploy it instantly using:
- **Netlify Drop**: Drag and drop the extracted folder.
- **Vercel**: Import project and deploy.
- **GitHub Pages**: Push files to a repository and enable GitHub Pages.
